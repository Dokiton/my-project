# Мәселе тұжырымы (5-сабақ)
> Бастапқы гипотеза. Сұхбаттан кейін түзетеміз.

## 1. Кімнің мәселесі (Аудитория)
* **Негізгі сегмент:** Қазақстандағы университеттер мен IT колледждерде бағдарламалау негіздерін (Python, алгоритмдер) оқитын 1–3 курс студенттері.
* **Қосалқы сегмент:** Практикалық және зертханалық сабақтарды жүргізетін, код тексеретін оқытушылар (ассистенттер, лекторлар).

## 2. Мәселе (5 бөлік)
* **Кім:** Бағдарламалауды енді меңгеріп келе жатқан 1–3 курс студенттері.
* **Жағдай:** Аудиториядан тыс уақытта (кешкі уақытта, демалыс күндері) зертханалық жұмыстар мен үй тапсырмаларының кодын өз бетінше жазу кезінде.
* **Қиындық:** Кодта синтаксистік немесе логикалық қателер (bugs) шыққанда, қатенің түпкі себебін түсіне алмайды және оқытушыдан жедел кері байланыс ала алмай, жұмысы сағаттап тоқтап қалады.
* **Қазір қалай шешеді:**
  - *Студенттер:* Ашық бұлттық жүйелерден (ChatGPT және т.б.) дайын шешімді көшіріп алады, бірақ код логикасын өздері түсінбейді;
  - *Оқытушылар:* Ондаған студенттің қайталанатын базалық қателерін әрқайсысына жеке-жеке қолмен тексеріп, түсіндіруге тырысады, бірақ уақыт жетпейді.
* **Неге маңызды:** Дайын кодты көшіру салдарынан студенттердің нақты білім сапасы төмендейді, академиялық адалдық бұзылады және зертханалық жұмысты қорғау кезінде өз шешімін дәлелдей алмайды. Ал оқу орындары үшін білім сапасының құлдырауы мен академиялық талаптардың бұзылуы негізгі тәуекел болып табылады.

## 3. Гипотезалар (Сұхбатта тексеріледі)

| Гипотеза | Қалай тексереміз (The Mom Test сұрақтары) |
|---|---|
| **Г1 (Уақыт пен кері байланыс тапшылығы):** Студенттер кодтағы қатенің мәнін түсінбегендіктен, оқытушының немесе курстастарының жауабын күтіп, тапсырманы орындауды тоқтатып қояды. | «Соңғы рет үй тапсырмасын орындау кезінде кодтан қате шыққанда не істедіңіз? Оны шешуге қанша уақыт кетті және кімге жүгіндіңіз?» |
| **Г2 (Дайын жауапты көшіру салдары):** Студенттер интернеттен немесе ЖИ-ден дайын кодты алып пайдаланғанымен, зертханалық жұмысты оқытушыға қорғау кезінде алгоритм логикасын түсіндіре алмай қиналады. | «Соңғы рет код жазу кезінде интернеттен немесе чат-боттан дайын шешім алған кезіңіз болды ма? Оқытушы сұрақ қойғанда қандай қиындықтар туындады?» |
| **Г3 (Қазақ тіліндегі техникалық контент тапшылығы):** Қазақ тілінде оқитын студенттер қателер мен техникалық терминдердің орыс/ағылшын тіліндегі түсіндірмелерін түсінуде кедергіге тап болады. | «Кодта қате шыққан кезде компилятор мен терминал хабарламаларын түсіну қаншалықты қиын болды? Шешімін қай тілде іздедіңіз?» |
| **Г4 (Оқытушының рутиналық жүктемесі):** Оқытушылар жұмыс уақытының басым бөлігін жаңа білім беруге емес, студенттердің бір типті синтаксистік қателерін қайта-қайта қолмен талдап көрсетуге жұмсайды. | «Өткен аптада студенттердің зертханалық жұмыстарын тексеруге қанша уақыт жұмсадыңыз? Ең көп қайталанатын қандай типтік қателер кездесті?» |
| **Г5 (Құпиялылық және академиялық шектеулер):** Білім беру мекемелері сыртқы бұлттық жүйелер арқылы оқу процесін жүргізуде академиялық адалдықтың бұзылуы мен деректер қауіпсіздігін басты тосқауыл деп санайды. | «Университетте сыртқы бұлттық ЖИ қызметтерін пайдалануға қатысты ресми ережелер немесе шектеулер бар ма?» |

## 4. MVP-ге кірмейді
- Кодты қауіпсіз виртуалды ортада орындап, автоматты компиляция нәтижесін тексеретін күрделі модуль (Sandbox / Code Runner).
- Студент пен оқытушы арасындағы нақты уақыттағы бейнеқоңыраулар мен жеке чаттар.
- Студентке оқытушының қатысуынсыз автоматты түрде қорытынды ресми емтихан бағасын қою.
- Мобильді қосымша (MVP нұсқасында тек веб-интерфейс қарастырылады).
